CareFlow project starter.
Frontend: index.html, style.css, app.js.
Backend: server/ (Express + Mongoose).
IMPORTANT: app.js API_BASE is a placeholder. Deploy server as an online Node service and replace it with the real deployed URL ending /api.
For local backend: in server folder run npm install; create .env from .env.example and set MONGODB_URI; then npm start.
GitHub Pages serves static files only; it cannot run server.js. Never commit .env or database credentials. This starter has no secure authentication; use fictional test data only and do not enter real patient information.
